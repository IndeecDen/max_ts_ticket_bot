# Релиз 1.0.5

Первый публичный релиз проекта [IndeecDen/max_ts_ticket_bot](https://github.com/IndeecDen/max_ts_ticket_bot).

## Состав

- приём MAX Webhook и надёжный inbox/outbox;
- сбор обращений и заявок с карточкой первого сообщения;
- кнопки взятия, завершения, отмены, назначения и переназначения;
- личное меню специалистов и администраторов с проверкой ролей;
- списки заявок, полный текст обращения и имена пользователей;
- личная и общая статистика, XLSX;
- объявления, стоп-слова, напоминания, дайджест и автоочистка;
- SQLite, ежедневные резервные копии, восстановление и обновление отдельными версиями;
- автоустановщик Debian 13 / Ubuntu 24.04 с systemd;
- SVG-логотип, пользовательская и серверная документация.

## Архив

```powershell
.\.venv\Scripts\python.exe scripts/build_release.py --version 1.0.5 --output dist/max-ts-ticket-bot-1.0.5.zip
```

Архив содержит исходники, тесты, документацию, SVG-логотип, установщик и systemd-шаблоны. Секреты, базы, `.env`, виртуальные окружения и журналы в архив не попадают. `SOURCE_MANIFEST.json` содержит SHA-256 файлов архива.

## Проверки

- 262 автономных теста на Python 3.12;
- тесты установки, обновления, миграций SQLite и резервных копий;
- проверка Bash/systemd-шаблонов;
- проверка релизного архива и исключения runtime-файлов;
- работа службы и обновление на Debian 13 подтверждены на тестовом сервере; чистая установка Ubuntu 24.04 и полное восстановление ещё требуют отдельных испытаний.

## Установка

```bash
git clone https://github.com/IndeecDen/max_ts_ticket_bot.git
cd max_ts_ticket_bot
sudo bash scripts/install.sh
```

После установки отдельно настройте HTTPS/reverse proxy и зарегистрируйте Webhook. Подробности: [QUICK_INSTALL.md](QUICK_INSTALL.md) и [LINUX_INSTALL.md](LINUX_INSTALL.md).

## Ограничения

Скачивание и повторная загрузка вложения при отказе пересылки не реализованы. Между SQLite и MAX нет гарантии «ровно один раз» для неопределённой сетевой отправки — такие задания требуют ручной сверки. Перед production-запуском проверьте права бота, Webhook, кнопки, XLSX и реальные вложения в тестовом чате.
