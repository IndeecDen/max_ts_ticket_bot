# MAX Ticket Bot v1.0.9

Обновление после v1.0.5 включает все изменения серверных сборок 1.0.6–1.0.9.

## Новое

- **🔒 Закрыть все** в настройках администратора: завершение новых заявок и заявок в работе с выводом количества. Обращения в стадии ожидания сохраняются.
- **📣 Рассылки** в личном меню администратора: HTML-текст, фото, файлы, видео и аудио с подписью или без неё.
- Предпросмотр с вложениями и новые кнопки под ним: **Отправить сейчас / По таймеру / Отменить**.
- Разовая отправка через указанное число минут либо в заданную дату по часовому поясу бота.
- Постоянное хранение текста, токенов вложений и расписания; восстановление после перезапуска.
- Отмена черновика и отложенной рассылки, проверка роли администратора, счётчики доставки.
- Реестр известных групп из истории и событий MAX; рабочий чат специалистов, диалоги и каналы исключены.
- Обновлены README и инструкции, добавлено руководство по рассылкам.

## Обновление существующей установки

Распакуйте релиз и запустите из каталога новой версии:

```bash
sudo bash scripts/update.sh
```

Скрипт создаст проверенную резервную копию и отдельный каталог версии. Миграции SQLite **19 → 20 → 21** сохраняют заявки, сообщения, роли и настройки.

После обновления добавьте события `bot_added` и `bot_removed` в подписку штатной командой из актуального каталога службы:

```bash
cd "$(systemctl show max-ts-ticket-bot.service --property=WorkingDirectory --value)"
sudo -u max-ts-ticket-bot .venv/bin/python -m app.setup_webhook register --profile /etc/max-ts-ticket-bot/config.json
```

Откройте `/menu` заново. Черновики, созданные старой версией без вложений, нужно пересоздать для включения фото или файла.

## Проверки и ограничения

- **273 автоматических теста**, включая вложения, таймер, отмену, права и миграции.
- Серверное обновление проверено на Debian 13; профиль и существующие данные сохранены, `/readyz` — `ready`.
- Текст ограничен 4000 единицами UTF-16 с учётом HTML-тегов.
- Получатели — известные группы; старую группу без событий можно зарегистрировать сообщением `/whoami` непосредственно в ней.
- Повторное использование вложений требует токена MAX. Неподдерживаемое вложение отклоняется целиком.
- Реальное отображение конкретных типов медиа проверьте в предпросмотре. Неопределённые сетевые отправки требуют ручной сверки.
