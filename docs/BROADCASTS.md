# Массовые рассылки

В личном диалоге администратора: `/menu` → **📣 Рассылки** → **✏ Новая рассылка**.

1. Введите сообщение с HTML-разметкой (до 4000 символов UTF-16, включая теги) либо отправьте фото/файл с подписью одним сообщением. Вложение без подписи также поддерживается.
2. Бот отправит отдельное сообщение-предпросмотр.
3. Выберите **🚀 Отправить сейчас**, **🕒 По таймеру** или **✖ Отменить**. Отмена также доступна при вводе времени и после ошибки ввода; черновик помечается отменённым и не отправляется.
4. Для таймера введите число минут, например `30`, либо дату `2026-10-15 09:00`. Часовой пояс показан в меню и берётся из профиля бота.

Пример:

```html
<b>Плановые работы</b>
Сегодня с 18:00 до 19:00 сервис будет недоступен.
<i>Спасибо за понимание!</i>
<a href="https://example.org">Подробности</a>
```

Поддерживаются `b`, `strong`, `i`, `em`, `u`, `s`, `del`, `code`, `pre` и ссылки `a href` с HTTP/HTTPS. Переносы строк вводятся обычным Enter. Для буквальных символов `<` и `&` используйте `&lt;` и `&amp;`. Форматирование задаётся тегами в тексте, а не инструментами выделения клиента MAX.

Фото, файлы, видео и аудио отправляются повторно по токенам MAX, сохранённым в SQLite вместе с подписью. Файл или аудио должны быть единственным вложением сообщения. Неподдерживаемые вложения и вложения без токена отклоняются целиком — текст без них не рассылается. Загрузите такой файл напрямую вместо пересылки. Предпросмотр содержит те же вложения; кнопки выбора отправляются новым сообщением после него. Недоступный токен приводит к ошибке доставки, а не отправке одного текста.

## Получатели

Все известные боту групповые чаты, кроме рабочего чата специалистов. Личные диалоги и каналы исключены. Список фиксируется при наступлении времени отправки: учитываются добавления и удаления бота до этого момента.

Реестр восстанавливается из сохранённой истории входящих событий и затем обновляется по сообщениям и событиям `bot_added`/`bot_removed`. Если старая группа не представлена в истории, отправьте в неё сообщение после обновления. Количество известных групп отображается в меню.

При обновлении существующей установки зарегистрируйте новые типы событий через `app.setup_webhook register --profile /etc/max-ts-ticket-bot/config.json` из актуального каталога службы и её `.venv`. Используются `message_created`, `message_callback`, `bot_added`, `bot_removed`.

## Расписание и доставка

Рассылка разовая; текст и время сохраняются в SQLite и переживают перезапуск. Пропущенная во время простоя отправка запускается после старта. До запуска её можно отменить в списке рассылок. При отзыве роли администратора запланированные им рассылки отменяются перед запуском.

Список показывает последние 10 рассылок и количество отправленных, ожидающих, выполняемых и ошибочных заданий. «В очереди» означает, что список получателей уже сформирован; итог смотрите по счётчикам. В частности, нулевые счётчики означают отсутствие получателей при запуске.

Используется общая очередь с ограничениями скорости и приоритетом ответов на кнопки. Перезапуск не создаёт повторные задания. Неопределённые сетевые отправки требуют ручной сверки по обычной процедуре очереди, а не автоматического повтора. После запуска отмена рассылки недоступна.

«📢 Объявления» остаются отдельной функцией: они добавляют текст к новым карточкам клиента, а не отправляют сообщение всем группам.
